# Библиотека фонов KIBERONE VIBE CODING LAB

Поместите реальные фоновые изображения формата 16:9 (1280×720, .jpg или .png) в соответствующие подпапки:

- `fantasy/` — фэнтези
- `mystery/` — мистика и детектив
- `scifi/` — научная фантастика
- `adventure/` — приключения
- `modern/` — современная история

Все пути к изображениям настраиваются в едином конфигурационном файле:
`src/config/backgroundLibrary.ts`

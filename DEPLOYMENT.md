# Проверка и публикация KIBERONE GAME CREATOR ADVENTURE

## 1. Проверка production-сборки локально на Windows

Откройте терминал (PowerShell или CMD) в распакованной папке проекта и выполните:

```powershell
npm ci
npm run lint
npm run build
npm run preview
```

После `npm run preview` Vite выведет локальный адрес (обычно `http://localhost:4173/`). Откройте его в браузере (Chrome / Edge / Yandex).

> При локальной сборке базовый путь автоматически устанавливается в `/`.
> При сборке в GitHub Actions (`GITHUB_ACTIONS=true`) базовый путь автоматически переключается на `/kiberone-game-creator-adventure/`.

## 2. Проверочный список ручного тестирования в браузере

Откройте DevTools (`F12` → вкладки **Console** и **Network**) и убедитесь, что нет красных ошибок и запросов со статусом `404`:

1. **Главная страница**:
   - Для нового ученика отображается приветствие, КиберБот, иллюстрация новеллы и кнопка «Начать приключение» (без JSON-кнопок и старых XP).
   - После сохранения прогресса на главной появляется карточка с этапом, XP, ключами и подтверждением сброса при нажатии «Начать новое приключение».
2. **КиберБот**: отображаются все эмоции персонажа без обрезания и битых иконок.
3. **Этап 1 (Разминка Python)**: проходятся все 5 концепций, у переменной виден контейнер `hero = "Алина"` и `energy = 100`.
4. **Этап 2 (Жанр и стиль)**: загружаются все 5 карточек жанров, все 6 карточек стилей (`object-contain` на белом фоне) и интерактивный макет слоёв.
5. **Этап 3 и Этап 4 (Сюжет и сценарий)**: работают 4 шага конструктора сюжета, валидация дублирующихся выборов, защита от вставки промпта вместо ответа ИИ и чек-лист из 6 частей.
6. **Этап 5 (Фоны)**: фильтрация показывает строго подходящие локации для выбранного жанра и стиля (до 6 карточек) или честное сообщение с кнопкой «СОЗДАТЬ СВОЙ ФОН В GOOGLE FLOW».
7. **Этап 6 и Этап 7 (Персонаж и прозрачный PNG)**: 4 шага создания персонажа, загрузка картинки, проверка реального альфа-канала на клеточках прозрачности и примерка героя на фон.
8. **Этап 8 и Этап 9 (Python + Тест)**: мини-квест (порог 3 из 5), генерация промпта с подстановкой готового сценария, чек-лист отладки.
9. **Мини-квесты ожидания и сундуки**: на экране ожидания работает переход «Пройти ещё один мини-квест» и подсказки при ошибке; открываются сундуки на этапах 3, 6, 9, 10 с разными иллюстрациями и стикерами; работает «Карта приключения».
10. **Этап 10 (Грамота) и сохранение**:
    - После ввода имени и финального названия игры скачиваются файлы **PNG** и **PDF (A4 альбомный)** с корректной кириллицей.
    - После перезагрузки страницы (`F5`) прогресс сохраняется в `localStorage`.
    - В **Режиме преподавателя** работают таймер, слайды, заметки и экспорт/импорт резервной копии JSON.

## 3. Инструкция: как скачать ZIP, распаковать и опубликовать на GitHub Pages

1. **Скачайте ZIP проекта** и распакуйте его в отдельную папку на компьютере (например, `C:\Projects\kiberone-game-creator-adventure`).
2. **Создайте новый публичный репозиторий на GitHub** с точным названием:
   `kiberone-game-creator-adventure`
   (без инициализации README/.gitignore, чтобы не было конфликтов).
3. **Откройте терминал в папке проекта** и загрузите файлы в ветку `main`:
   ```bash
   git init
   git branch -M main
   git add .
   git commit -m "Prepare KIBERONE Game Creator Adventure for GitHub Pages"
   git remote add origin https://github.com/<ВАШ_ЛОГИН>/kiberone-game-creator-adventure.git
   git push -u origin main
   ```
   *(Либо загрузите все файлы проекта в ветку `main` через веб-интерфейс GitHub, сохранив папки `.github/workflows/`, `src/`, `public/`, `scripts/`, `package.json`, `package-lock.json`, `vite.config.ts`, `index.html`.)*
4. **Включите GitHub Pages в настройках репозитория**:
   - Откройте репозиторий → **Settings** → **Pages**.
   - В разделе **Build and deployment → Source** выберите **GitHub Actions**.
5. **Запустите и проверьте деплой**:
   - Перейдите во вкладку **Actions** и дождитесь завершения workflow **Deploy KIBERONE Game Creator Adventure to GitHub Pages** (зелёная галочка).
   - Готовый сайт откроется по адресу:
     `https://<ВАШ_ЛОГИН>.github.io/kiberone-game-creator-adventure/`
